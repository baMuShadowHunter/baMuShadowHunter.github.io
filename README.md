# 🌐 BaMu Portfolio

A personal portfolio website of **Balamurugan (BaMu)**, a Fullstack Developer, built with pure **HTML, CSS and JavaScript**.

🔗 **Live Site:** [bamushadowhunter.github.io](https://bamushadowhunter.github.io/)

---

## 📖 About

This portfolio showcases who I am, what I've built, and what I've achieved. I'm a technical person who picks up new technologies quickly and applies them to real-world projects.

## ✨ Features

- 📱 Fully responsive design (mobile, tablet, desktop)
- 🧭 Navbar with hamburger menu for small screens
- 🙋 About section with collapsible Skills, Achievements and Education lists
- 💼 Projects section with a "Show More" page for all projects
- 🏆 Achievements and Certificates page with a lightbox image viewer (next/previous navigation)
- ✍️ Blog section linking to my tech blog
- 📬 Contact section with social links, contact form and downloadable CV
